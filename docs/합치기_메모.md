## 0. 무엇보다 먼저 — 집 작업을 커밋한다

받기 **전에** 집에 있는 것부터 묶는다. 이걸 안 하면 합치는 도중에 날아갈 수 있다.

```bash
git add -A && git commit -m "집에서 하던 것 — 합치기 전 저장"
```

## 2. 씬은 집 것을 살린다

이날 씬에서 바뀐 값은 **아래가 전부**다. 집 씬 작업(카메라·바닥·애니메이터)이 훨씬 크므로
**집 씬을 그대로 두고 이 값만 다시 넣는다.**

```bash
git checkout --ours Assets/Scenes/SampleScene.unity   # 합치는 중 충돌났을 때
git add Assets/Scenes/SampleScene.unity
```

## ★이 사달이 난 이유 (다시 겪지 않으려면)

2026-08-10 에 반나절을 여기에 썼다. 원인은 하나다 —
**집에서 한 작업이 커밋·푸시되지 않은 채 남아 있었고, 다른 컴퓨터에서는 그것이 존재하지
않는다는 사실을 아무도 몰랐다.**

· 저장한 파일은 사라지지 않는다. 다만 **커밋·푸시하지 않으면 그 컴퓨터를 벗어나지 못한다**
· 플레이(▶) 를 켠 상태에서 만진 인스펙터·애니메이터 값은 **멈추면 되돌아간다**
· 씬 편집은 **Ctrl+S** 를 해야 파일에 남는다

→ **작업을 끝낼 때마다 커밋·푸시한다.** 시작할 때는 `git status` 로 남은 것이 있는지 먼저 본다.
