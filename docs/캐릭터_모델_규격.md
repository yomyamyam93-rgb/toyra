# 캐릭터 모델 규격 — 새로 만들 때 반드시 맞출 것

*(2026-08-12. 사람 모델을 다시 만들기로 하면서 정리했다. **게임 코드가 요구하는 것**만 적는다 —
아트 방향은 [스타일_프롬프트.md](스타일_프롬프트.md) 와 정본 6장에 있다.)*

★★**이 문서가 있는 이유:** 유니티는 **애니메이션·뼈 경로가 틀려도 에러를 안 낸다.** 조용히
무시한다. 뼈 이름 하나가 달라지면 그 뼈를 쓰는 자세가 **안 움직이는데 콘솔은 깨끗하다.**
그래서 눈으로 보거나 값을 재야만 안다 (정본 9-2). 미리 맞추는 게 훨씬 싸다.

## 1. 크기와 원점

| | 값 | 왜 |
|---|---|---|
| 키 | **1.8m** | 세계의 자 (정본 3장). 축소 배율을 만들지 않는다 |

| 정점 수 | **3,000 ~ 5,000** | 화면 가로가 50m라 사람은 화면의 **3.6%** 다. 지금 남자는 161,563 개 — 40배 넘는다 |

## 2. ★뼈 이름 — 하나도 바꾸지 말 것

코드가 **이름으로** 찾는다. 24개가 필수다.

```
Hips                                    ← 뿌리
 └ Spine02        ← ★허리 (이름과 순서가 반대다! 아래 주의)
    └ Spine01     ← 등
       └ Spine    ← 가슴
          ├ neck  (소문자다)
          │  └ Head
          │     ├ head_end
          │     └ headfront
          ├ LeftShoulder  → LeftArm  → LeftForeArm  → LeftHand
          └ RightShoulder → RightArm → RightForeArm → RightHand
 ├ LeftUpLeg  → LeftLeg  → LeftFoot  → LeftToeBase
 └ RightUpLeg → RightLeg → RightFoot → RightToeBase
```

### ★★주의 — 척추 순서가 이름과 반대다

**`Hips → Spine02 → Spine01 → Spine`** 순서다. 숫자가 큰 쪽이 아래(허리)고, 숫자 없는 `Spine`
이 맨 위(가슴)다. 이름만 보고 뒤집으면 **몸이 거꾸로 접힌다.**
`neck` 은 **소문자**다.

### 손가락 (10개) — ★남자에도 넣어야 한다

```
LeftHandFingers1 → LeftHandFingers2 → LeftHandFingers3
LeftHandThumb1   → LeftHandThumb2
RightHandFingers1 → RightHandFingers2 → RightHandFingers3
RightHandThumb1   → RightHandThumb2
```

지금 **여자만 있다** (2026-08-09 작업). 남자는 손가락이 없어서 `HeroAttack.주먹` 이 켜져 있어도
**주먹을 못 쥔다** — 아무 일도 안 일어난다.

## 3. 코드가 실제로 만지는 뼈 — 누가 어느 뼈를 쥐나

★**소유권이 갈려 있다.** 두 곳이 같은 뼈를 만지면 헛돈다 (2026-08-12 에 이걸로 한 번 걸렸다).

| 뼈 | 누가 쥐나 | 무엇에 |
|---|---|---|
| `RightShoulder` `RightArm` `RightForeArm` | **HeroHold** | 무기 들기 · 치기 · 집어들기 · 줄 끌기 · **주먹** |
| `LeftArm` `LeftForeArm` | **HeroHold** | 두 손 자세 · 감싸 안기 · 뒷손 · **왼주먹** |
| `Hips` `Spine02` `Spine01` `Spine` `Head` | **둘 다** (얹기만) | 몸통 스윙 · 숙임 · 젖힘 |
| `LeftUpLeg` `LeftLeg` `LeftFoot` | **HeroAttack** | 웅크림 · 내딛기 |
| `RightUpLeg` `RightLeg` `RightFoot` | **HeroAttack** | 웅크림 · 내딛기 · **발차기** |
| `RightHand` `RightForeArm` | HeroAttack (읽기만) | 무기를 쥐여 놓을 축 |

★`Hips`~`Head` 는 **덮어쓰지 않고 얹는다** — 그래서 걷기 클립과 같이 돌 수 있다.
팔·다리는 **덮어쓴다** — 그래서 클립과 절차 모션이 다투면 클립이 이긴다.

---

## 4. ★부위를 여덟으로 가른다 — 메시 오브젝트 이름을 이렇게

장비창(Tab)의 칸과 **짝을 맞춘다.** 이름이 같으면 코드가 저절로 연결한다.

| 메시 오브젝트 이름 | 장비창 칸 | 무엇이 들어가나 |
|---|---|---|
| `머리` | 머리 | 두개골·머리카락 (모자를 쓰면 이 위에 덮인다) |
| `얼굴` | 얼굴 | 눈·입 (★그리지 않는다 — 점 두 개면 된다, 정본 6장) |
| `목` | 목 | 목 |
| `상의` | 상의 | 몸통·팔 |
| `하의` | 하의 | 골반·다리 |
| `장갑` | 장갑 | 손 |
| `신발` | 신발 | 발 |
| `가방` | 가방 | (몸에는 없음 — 아이템이 붙는 자리) |

☆**가르는 규칙:** 같은 뼈대(아마추어)를 **공유**한다. 부위마다 뼈대를 따로 만들면 안 된다.
☆부위를 안 가르면 그 칸은 갈아끼울 수 없다. 지금은 통짜(서브메시 1개)라 **전부 불가능**하다.

## 6. 내보내기

- 형식: **glTF (.glb)** — 지금 쓰는 형식이다
- 넣는 곳: `Assets/Game/Models/hero/`(여자) · `Assets/Game/Models/hero_man/`(남자)
- ★**메시와 애니메이션을 같은 파일에 섞지 말 것.** 지금은 메시 원본이 `Walking.glb` 라는
  **애니메이션 파일**이다 — 어느 파일이 몸인지 알 수 없다. 몸은 몸으로, 동작은 동작으로 낸다
- 재질은 유니티에서 갈아끼운다 (`살.mat`). 블렌더 재질 이름은 안 중요하다

## 7. 만든 뒤 확인할 것 — ★눈으로 보거나 값을 재야 안다

1. **키가 1.8m 인가** — 사람 기둥 옆에 세워 본다
2. **발이 땅에 닿나** — 원점이 바닥인지
3. **`HeroHold` 자세가 도나** — 좌클릭을 눌러 팔이 올라가는지. 안 올라가면 뼈 이름이 틀린 것
4. **주먹이 쥐어지나** — 손가락 뼈가 있는지
5. **부위가 갈렸나** — 유니티 인스펙터에서 스킨메시가 **여덟 개**로 보이는지 (지금은 한 개)
6. **정점 수** — 인스펙터에 뜬다. 3~5천이면 됐다

☆3번이 특히 중요하다 — **틀려도 에러가 안 난다.** 팔이 안 올라가면 그게 신호다.
