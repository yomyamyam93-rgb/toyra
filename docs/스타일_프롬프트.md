**쓰는 법:** 아래 블록을 통째로 복사 → 맨 끝 `만들 것:` 뒤에 한 줄만 적는다. 끝.

> 예) `만들 것: 나무로 된 트리케라톱스`

## 마지막 줄에 적는 법

짧게, **무엇이 무엇으로 되어 있는지**만.

```
만들 것: 나무로 된 트리케라톱스
만들 것: 쇠로 된 작은 늑대 공룡
만들 것: 이끼 낀 바위 무리
만들 것: 가죽옷을 입은 원시인 남자
만들 것: 돌과 나무로 엮은 울타리
```

**재질을 영어로 쓸 때:**

| | |
|---|---|
| 나무 | carved wood |
| 쇠 | brushed metal |
| 플라스틱 | molded plastic |
| 유리 | translucent colored glass |
| 고무 | soft matte rubber |

★재질은 겉모습만 정한다. 스탯을 정하지 않는다 (`CLAUDE.md` 6장).

## 크기를 같이 적고 싶다면

**사람 키 1.8m 를 기준으로** 적는다. 이 게임은 1유닛 = 1미터라, 크기가 어긋나면
세계가 통째로 어긋난다.

```
만들 것: 나무로 된 트리케라톱스, 사람 가슴 높이 (1.3m)
```
