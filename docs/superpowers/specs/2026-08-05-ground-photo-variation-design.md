# 땅 재질 — 사진을 그대로, 자리마다 다르게

2026-08-05 · 사용자 확정

## 왜

바닥이 **도트로 보이는 게 싫다**는 데서 출발했다. 살펴보니 도트는 효과가 아니라
해상도였고(`PixelScreen` 이 저해상도 판 한 장에 전부 그린다), 그건 카메라를 가르지
않으면 못 뺀다. 대신 **재질 자체가 깎여 있던 것**이 진짜 문제였다 —
`GroundImport` 가 넣는 족족 64px·점 필터로 줄이고, 색까지 빼서 회색 명암으로만 썼다.

사용자가 진짜 재질 13장을 넣고 말했다: **"픽셀버전으로 변형하지말고 그대로 넣어줘."**
그리고 **"5칸으로 제한하면 안 되고 함수 사용해서 어디는 많이쓰고 어디는 적게쓰고 랜덤하게."**

## 결정

| 갈림길 | 정한 것 | 버린 것 |
|---|---|---|
| 색의 주인 | **사진** (A안) | 여섯 색 잔디 팔레트 — 이제 물에만 남는다 |
| 섞는 단위 | **노이즈 밭** (경계선 없음) | 칸(160m) 단위 배정 — 격자가 드러난다 |
| 장수 | **제한 없음** (폴더에 넣으면 는다) | 슬롯 N개 고정 |

### 배합 함수

사진 `i` 마다 자기 노이즈 밭 하나:

```
w_i(x,z) = ( noise(월드xz · 주파수_i + 오프셋_i) + 편향_i ) × 자리무게
```

- **주파수** 25~90m — 어떤 사진은 넓게, 어떤 건 잘게
- **오프셋** — 밭끼리 안 겹치게
- **편향** ±0.35 — ★「어디는 많이, 어디는 적게」가 여기서 나온다. 씨앗을 바꾸면 세상의
  주인 사진이 바뀐다
- **자리무게** — 그 자리가 무엇이냐 (잔디/흙/돌). 후보 안에서만 섞이므로 잔디 위에
  진흙이 안 튄다

### 어느 사진을 뽑나 — 꼭대기 근처만

가장 높은 가중치(`peak`)에서 `_PhotoBand` 안에 든 것만 색에 참여하고, 나머지는 0.
사진이 꼭대기에 가까워지면 **스르르 끼어들고** 멀어지면 스르르 빠진다.

★「제일 진한 둘만 골라 섞기」는 **쓰면 안 된다** — 2등과 3등이 뒤바뀌는 자리에서
가중치는 같은데 색이 달라 **뚝 끊긴다.** 이 방식은 그 자리에서 둘 다 0 에 가까워
끊길 것 자체가 없다.

## 구조

```
Resources/ground/사진/{잔디,흙,돌}/*   원본 사진 (안 깎는다)
        │
GroundPhotoImport (에디터)   Bilinear · 밉맵 · 2048 상한 — GroundImport 와 정반대
        │
GroundPhotos.준비(seed)      13장 → Texture2DArray 1024px 한 장 + 밭 파라미터
        │
WorldGen.사진꽂기()           재질에 배열·파라미터·바위지도를 꽂는다
        │
Toyra/Ground (셰이더)        픽셀마다 밭을 재고 꼭대기 근처만 섞는다
```

- **바위지도** — 칸(160m)마다 `바위지대` 여부를 적은 9×9 그림. 부드럽게 늘려 뽑아
  경계가 안 보인다. 바위지대에서만 돌바닥 사진이 잔디 자리를 뺏는다.
- **`_PhotoNum == 0` 이면 옛 갈래**(팔레트 × 회색 결)로 그대로 돌아간다. 은퇴는 스위치.

## 대가 (알고 받아들인 것)

1. **1024px 리샘플** — 배열로 묶으려면 크기가 같아야 한다. 원본 360~1250px 이 전부
   1024 로 다시 그려진다. **픽셀 변환이 아니라 리샘플**이다 (Bilinear·밉맵·aniso 8).
2. **메모리 54MB** (13 × 1024² × RGBA32). 줄이려면 `사진크기` 를 512 로.
3. **모래 자리는 흙 사진을 쓴다** — 모래 사진이 없다.
4. **되풀이** — 사진 한 장이 5m 를 덮는다. 화면(픽셀당미터 30)에서 150px 마다 되풀이다.
   눈에 띄면 `사진칸` 을 키운다. 사진마다 uv 배율을 0.8~1.3 으로 흔들어 두긴 했다.
5. **잔디 포기 색은 아직 팔레트를 따른다** — `GrassField` 가 `땅그림`(팔레트로 칠한 것)을
   읽는다. 사진이 색을 쥐게 됐으므로 여기가 어긋날 수 있다. **다음 할 일.**

## 손잡이 (WorldGen 인스펙터)

| 이름 | 기본 | 하는 일 |
|---|---|---|
| 땅사진 | 켬 | 끄면 옛 방식 |
| 사진칸 | 5m | 사진 한 장이 덮는 크기 |
| 사진크기 | 1024 | 배열 한 변 |
| 사진섞임 | 0.18 | 작으면 또렷하게 갈리고 크면 뭉근하다 |
| 사진명암 | 0.12 | 큰 명암 흔들기 (색은 안 건드린다) |
| 바위지대돌 | 0.75 | 바위지대에서 돌바닥이 드러나는 정도 |

## 확인한 것 (2026-08-05 실측)

- 사진 13장 전부 Bilinear·밉맵으로 임포트 — 안 깎였다
- 셰이더 에러 0 · 콘솔 에러 0
- `[땅사진] 13장 · 1024px · 잔디 5 흙 6 돌 2`
- 재질에 `Texture2DArray 1024x1024 ×13 RGBA32 mip11 aniso8` 바인딩 확인
- ★**Properties 에 안 적은 텍스처는 `Material.SetTexture` 로 안 들어간다** — 배열이
  통째로 비어 있었다. float·벡터배열은 안 적어도 들어가서 더 헷갈렸다
