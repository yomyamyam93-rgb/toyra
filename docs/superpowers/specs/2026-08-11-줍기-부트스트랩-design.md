# 줍기 부트스트랩 — 바닥의 나뭇가지·돌맹이가 도구 사슬을 연다 (2026-08-11 확정)

사용자 발단: *"바닥에 나뭇가지나 돌맹이들을 좀 깔아야 하지 않을까? 그래야 줍지,
몽둥이로 캐는 게 말이 안 돼서."* + *"바위도 안 캐져서 이것도 고쳐야 할 듯."*

확정된 갈래 (질문 셋의 답):
- **범위 = 부트스트랩 재편** — 줍기만 얹는 게 아니라 채집 조건까지 (몽둥이는 무기로 돌아간다)
- **줍은 것 = 기존 재료와 같다** — 나뭇가지 = 나무 ×1 · 돌맹이 = 돌 ×1 (새 아이템 종 없음)
- **줍기 조작 = 정통 좀보이드** — Tab 창의 「앞에 있는 것」 패널로만 (새 조작 없음)

---

## ① 바닥 줍이 — 어디에 무엇이 깔리나

칸 종류(`WorldGen.KindAt`)가 정한다 (헌법 5-4 그대로):

| 칸 | 깔리는 것 | 어디에 |
|---|---|---|
| 숲 | **나뭇가지** | 나무 밑 주변 산포 |
| 바위지대 | **돌맹이** | 바위 곁 |
| 빈들판 | 둘 다 | 아주 드물게 |

- 나뭇가지 = 가늘고 긴 갈색 막대 눕힘 (색칠한 상자 먼저, 프리팹 교체 자리는 나중에).
- **★돌맹이는 새로 안 깐다** (2026-08-11 사용자 — "돌맹이는 많으니까 그 돌맹이 써줬으면").
  `WorldGen`이 이미 장식으로 깔아 둔 「돌멩이」 상자를 그대로 줍이로 만든다 —
  보이는 것과 주울 수 있는 것이 같아진다.
- 알맹이는 **기존 `땅무더기`로 실존** — 줍이 하나 = 땅무더기 하나 (나무 ×1 또는 돌 ×1).
  다 집으면 바닥 프롭이 사라진다.
- **다시 안 자란다** (헌법 "다시 자라는 건 나중에" 그대로).
- 밀도는 짐작하지 않고 **깔아 놓고 화면을 보며** 정한다. 초안: 숲 칸당 나뭇가지 8~14 ·
  바위지대 칸당 돌맹이 6~10 · 빈들판 칸당 0~3.

## ② 줍기 — 정통 좀보이드

새 조작·새 UI 없음. 줍이 곁에서 **Tab → 오른쪽 「앞에 있는 것」 → 클릭**
(이미 있는 인벤창·땅무더기 그대로). 겨누면 기존 대상표시의 주황(만질것) 외곽선.

## ③ 도구 재편 — 「도구가 행위를 연다」를 실제로 배선

지금 도구는 제작 조건(`제작법표.도구있나`)에만 걸리고 **채집 속도에는 아무 영향이 없다.**

- 칠 때 가진 것 중 **맞는 도구를 저절로 쓴다** — 나무 ← 도구쓰임 "나무"(돌도끼) ·
  돌 ← "돌"(돌곡괭이). 이미 있는 `인벤.어느통에든도구` 재사용.
- **도구 있음 = 지금 속도 × 성능** · **도구 없음(맨손·몽둥이) = 3배 느림** —
  헌법 5-4 "되긴 하되 아주 느리다, 아예 막으면 답답하다" 그대로.
- 채집에 쓰면 **도구가 닳는다** (이미 있는 닳음 재사용).
- 몽둥이는 도구가 아니다 — 무기로 돌아간다.

## ④ 바위 수리 (버그)

`WorldGen.Rocks()`: 프리팹으로 선 바위는 `continue` 때문에 **Harvest가 안 붙어
아예 캘 수 없다** — 나무가 옛날에 앓았던 「문 둘」 병과 같은 모양 (9-2).
무엇으로 서든(프리팹이든 상자든) 같은 경로로 Harvest를 붙인다.

## ④-1 연출 — 몸이 하는 일을 보여준다 (2026-08-11 사용자 추가)

- **나무 쓰러짐 3막**: 쭈우우욱 기울다(예비) → 가속하며 넘어가고(본동작) →
  착지 순간 **잎이 펄럭이며 흩날리고** 캐노피가 사라지며 통나무가 남는다(여운).
  지금은 착지에 잎을 `Destroy` 로 즉시 지운다 — 펄럭임이 그 자리를 잇는다.
- **돌 캐기 = 돌맹이가 튄다**: 몇 대 팰 때마다 **돌맹이 줍이가 주변에 툭툭 떨어진다.**
  돌은 인벤에 바로 꽂히지 않는다 — **떨어진 돌맹이를 줍는 것이 수확이다** (9-0 인과:
  결과는 행위에서). 돌곡괭이의 "빨리 캔다"는 = 더 자주·더 많이 튄다.
  ☆이펙트 규칙에 맞다 — 지우면 무슨 일이 일어났는지 못 알아보는 표현만 넣는다.

## ⑤ 부트스트랩 사슬 = 성공 기준

```
맨몸+몽둥이 시작
→ 숲에서 나뭇가지 2 줍기 + 바위지대에서 돌맹이 3 줍기 (Tab 패널)
→ 돌도끼 제작 → 나무가 제대로 패진다 (3배 빨라짐)
→ 나무 3 + 돌 4 → 돌곡괭이 → 바위가 제대로 캐진다
```

- **제작법 표는 한 줄도 안 바뀐다** (재료가 이미 나무·돌이라).
- 제작창은 좀보이드식 그대로 — 전 목록 + 흐림 + `나무 0/2` 표시가 뭘 모을지 알려준다.
  벽화 잠금(탐험이 제작을 연다)은 이 작업과 무관, 헌법 계획대로 나중.
