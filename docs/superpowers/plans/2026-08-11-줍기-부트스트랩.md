# 줍기 부트스트랩 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) 구문.

**Goal:** 바닥의 나뭇가지·돌맹이를 주워 도구 사슬을 시작한다 — 몽둥이는 무기로 돌아가고, 도구가 채집 속도를 정하고, 바위가 실제로 캐지고, 나무는 3막으로 쓰러진다.

**Tech Stack:** Unity 6000.3.20f1 · URP · 새 Input System 전용

### Task 4: 도구 배선 — 맞는 도구 = 지금 속도, 맨손 = 3배 느림

기존 숫자(hits·perHit)를 **하나도 안 바꾸는** 방식: 한 타의 진전을 틱으로 센다. 맞는 도구(성능 3)면 매 타 진전, 맨손이면 3타에 한 번 진전.
